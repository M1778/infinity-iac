Infinity-IaC

A powerful, unified Infrastructure-as-Code tool designed for seamless application deployment using cloud-init.

Getting Started

Infinity-IaC allows you to quickly provision and deploy infrastructure across Oracle Cloud Infrastructure (OCI) and other providers.

infinity-iac setup
infinity-iac run --recipe nextcloud

Core Capabilities

  • Provider Agnostic Core: Designed to extend beyond OCI with standard cloud-init configurations.
  • Validation Preflight: Automatically validates access and permissions before provisioning.
  • Embedded Catalog: Shipped as a single binary with zero external dependencies.
