Infinity-IaC

A powerful, unified Infrastructure-as-Code tool designed for seamless application deployment using cloud-init.

Getting Started

Infinity-IaC manages Oracle Cloud Infrastructure (OCI) instances. Configure a real access profile before provisioning; other provider adapters and VCN lifecycle commands are not implemented.

infinity-iac list recipes --output json
infinity-iac recipe render --name nginx --port 8080

Core Capabilities

  • Provider Agnostic Core: Designed to extend beyond OCI with standard cloud-init configurations.
  • Validation Preflight: Automatically validates access and permissions before provisioning.
  • Embedded Catalog: Recipe definitions are embedded in the binary. Provisioning still needs an OCI profile and outbound package/image access.
